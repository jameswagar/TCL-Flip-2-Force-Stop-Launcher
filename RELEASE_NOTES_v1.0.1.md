# Force Stop v1.0.1

This point release applies the same uniform wallpaper shading used by Power Saver across the full app window.

## Changes

- Apply an even 85% window-level wallpaper dim behind the title, app list, labels, and controls.
- Preserve transparent list and row backgrounds so the shading does not vary between UI sections.
- Keep existing D-pad focus, root operations, protected-package policy, and Force Stop behavior unchanged.

## Version

- Version name: `1.0.1`
- Version code: `7`
